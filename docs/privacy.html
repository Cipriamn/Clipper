Privacy Policy

Last updated: 15 October 2026

Who uses Clipper

Clipper is a private tool used only by its owner, on the owner's own computer, with the owner's own Google account. It is not offered to anyone else.

Google user data accessed

Clipper uses YouTube API Services. With the owner's consent it requests these scopes for the owner's own channel:

  • youtube.upload: to upload videos the owner has approved.
  • youtube.readonly: to read the owner's own videos' processing status and public statistics (such as view counts).

How data is used, stored and shared

  • Data is used only to upload the owner's approved videos and to show the owner how those videos perform.
  • OAuth tokens are stored only on the owner's computer, in the macOS Keychain. Video statistics are stored only in a local database on that computer.
  • Google user data is not sold, not used for advertising, and not shared with or transferred to any third party.
  • Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local data is kept while the owner uses the tool and can be deleted at any time by deleting the local database and Keychain entries. Access can be revoked at any time at myaccount.google.com/permissions.
