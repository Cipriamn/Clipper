Privacy Policy

Last updated: 16 November 2026

Who uses Clipper

Clipper is a private tool used only by its owner, on the owner's own computer, with the owner's own Google and TikTok accounts. It is not offered to anyone else.

Google user data accessed

Clipper uses YouTube API Services. With the owner's consent it requests these scopes for the owner's own channel:

  • youtube.upload: to upload videos the owner has approved.
  • youtube.readonly: to read the owner's own videos' processing status and public statistics (such as view counts).
  • yt-analytics.readonly: to read the owner's own videos' retention and country breakdown; stored only locally and shown as returned, never used to compute a score or any other value.

TikTok user data accessed

Clipper uses TikTok Login Kit and the TikTok API. With the owner's consent it requests these scopes for the owner's own TikTok accounts only:

  • user.info.basic: to identify which of the owner's accounts is connected (open ID and display name).
  • video.list: to read the view counts of the owner's own public videos, by video ID, at fixed times after posting (such as 24 hours and 7 days).

Clipper does not post, edit or delete anything on TikTok, and reads no other user's data. Access can be revoked at any time in the TikTok app under Settings and privacy → Security → Manage app permissions.

How data is used, stored and shared

  • Data is used only to upload the owner's approved videos and to show the owner how those videos perform.
  • OAuth tokens are stored only on the owner's computer, in the macOS Keychain. Video statistics are stored only in a local database on that computer.
  • Google and TikTok user data is not sold, not used for advertising, and not shared with or transferred to any third party.
  • Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Local data is kept while the owner uses the tool and can be deleted at any time by deleting the local database and Keychain entries. Access can be revoked at any time at myaccount.google.com/permissions.
